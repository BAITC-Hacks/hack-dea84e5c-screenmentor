# ИИ Наставник / ЖИ Көмекші

> Контекстный помощник для людей, которые хотят уверенно пользоваться сайтами и веб-версиями Word/Excel. Он объясняет интерфейс простыми словами, показывает нужный элемент и оставляет действие за пользователем.

**Версия:** 0.24.20 · **Статус:** рабочий хакатонный прототип · **Языки:** қазақша и русский

![Логотип ИИ Наставника](extension/mentor-logo.png)

## Зачем нужен проект

Обычная инструкция часто не совпадает с тем, что пользователь сейчас видит на экране. ИИ Наставник появляется рядом с интерфейсом, объясняет назначение видимой кнопки или раздела, зачем она нужна и какой безопасный шаг сделать дальше.

Пример: пользователь может сказать «надо отправить это друзьям». Если на странице открыто наблюдаемое меню с командой «Поделиться» или «Копировать ссылку», помощник связывает запрос с этой командой. Если такого элемента нет, он просит открыть подходящее меню, а не придумывает маршрут.

Главная аудитория — начинающие пользователи, пожилые люди, школьники под присмотром и русско-/казахскоязычные пользователи с неуверенными цифровыми навыками.

## Что умеет

| Возможность | Как это работает |
| --- | --- |
| Изучить страницу | Собирает ограниченный список видимых кнопок, полей и разделов, затем объясняет их по одному и подсвечивает цель. |
| Что это? | Пользователь выбирает кнопку или поле на странице; действие сайта не выполняется, а помощник объясняет элемент. Вложенная декоративная разметка не мешает распознать семантическую ссылку или пункт навигации; внешняя иконка с безопасным `title`/`aria-label` тоже передаётся как подписанная ссылка, без её адреса. |
| Объяснить раздел | Выбор панели, навигации, списка или другого блока; содержимое карточек и списков не читается. |
| Задать вопрос | Пользователь вводит собственную цель и получает один безопасный следующий шаг. После ручного действия нажимает «Далее» для свежего анализа. |
| Голосовой вопрос | После остановки записи речь распознаётся и сразу передаётся в тот же сценарий вопроса. |
| Озвучивание | Ответ воспроизводится потоково через Azure Speech; если облачная TTS не настроена, используется только локальный голос нужного языка. |
| Қазақша / Русский | Новая установка начинается на казахском. Язык, который выбрал пользователь, остаётся в панели и настройках расширения до следующего ручного переключения. |
| Защита от опасных сайтов | Google Safe Browsing V5 и локальные признаки адреса показывают небольшое предупреждение только при риске. Чистый сайт не получает сообщение «сайт безопасен». |
| Меньше рекламы | Небольшой отключённый по умолчанию фильтр работает только в выбранной вкладке. |
| Word и Excel Online | Подготовленные двуязычные объяснения проверенных команд без чтения текста документа, ячеек или имени файла. Для команды с другой вкладки ленты сначала показывает эту вкладку, затем называет команду. |

На всех сайтах, кроме Word/Excel, назначение элементов определяет ИИ по свежему снимку интерфейса. Готовых объяснений и словарей команд Gmail/GitHub нет. При недоступной модели показывается ошибка, а не шаблонная справка. Метаданные фильтруются, но произвольный aria-label может содержать имя пользователя: эвристики не гарантируют полного обезличивания.

## Чего помощник не делает

- Не нажимает кнопки, не вводит текст, не оплачивает, не отправляет сообщения и не меняет настройки вместо пользователя.
- Не читает полный HTML, текст чатов, документы, значения ячеек, значения полей, пароли, cookies или историю браузера.
- Не гарантирует, что любой сайт безопасен, а ответ модели всегда безошибочен.
- Не является полноценным блокировщиком рекламы и не умеет надёжно распознавать все динамические или hover-меню.
- Не подменяет казахскую озвучку русским голосом.

Эти ограничения — часть дизайна безопасности, а не временная ошибка интерфейса.

## Архитектура

```text
Пользователь
  ↓
Chrome/Edge extension (плавающая панель, popup, offscreen audio)
  ↓ безопасные descriptors видимых элементов
Service worker расширения
  ↓ Bearer pairing token (только локальный/хакатонный режим)
Node.js backend
  ├─ справка только Word/Excel и временный cache ответов ИИ
  ├─ Qwen / GLM / локальный Ollama
  ├─ Azure Speech: распознавание и потоковая озвучка
  └─ Google Safe Browsing V5: только hash-prefixes URL
```

Расширение передаёт модели не снимок страницы, а очищенный ограниченный контекст: тип элемента, безопасную подпись, группу, роль и состояние. Вопрос пользователя отправляется только после явного нажатия кнопки или успешного голосового ввода.

## Доступ пользователей

Текущая версия 0.24.20 использует pairing-токен для локальной разработки, хакатона и технического стенда. Обычным пользователям не следует выдавать `LOCAL_ACCESS_TOKEN`: в production планируется простой вход по номеру телефона или email с одноразовым кодом, а также ограниченный режим без регистрации.

Для школ и других учебных организаций целевой сценарий — код организации или invite-ссылка/QR-код. Такой код выдаёт администратор, он имеет срок действия, лимит активаций и отдельную квоту. Для подтверждения личности и статуса (например, школьник, студент или пожилой пользователь) рассматривается только официальный поток eGov/ЭЦП после отдельной privacy- и юридической проверки. ИИН не используется как пароль, не отправляется модели и не хранится в расширении.

Полная спецификация пользовательского доступа: [ACCESS_AND_ONBOARDING.md](docs/ACCESS_AND_ONBOARDING.md).

## Быстрый запуск локально

### 1. Требования

- Windows 10+;
- Node.js **22.x** (`>=22 <25`);
- Google Chrome или Microsoft Edge;
- ключ хотя бы одного поддерживаемого провайдера для ИИ-функций;
- Azure Speech key/region — только для голосового ввода и облачной озвучки;
- Google Safe Browsing API key — только для онлайн-проверки риска URL.

### 2. Установить зависимости и создать конфигурацию

```powershell
cd C:\путь\к\hackaton
npm ci
npm run setup
```

`npm run setup` создаёт `.env.local`, если его ещё нет, и локальный `LOCAL_ACCESS_TOKEN`. Не публикуйте `.env.local`: в нём ключи и код подключения.

Минимальная конфигурация выглядит так:

```dotenv
MODEL_PROVIDER=glm
LOCAL_ACCESS_TOKEN=<64-символьный hex-код>
GLM_API_KEY=<ваш ключ Z.ai>
GLM_MODEL=glm-5.3-flash
MAX_CALLS_PER_RUN=30

# Необязательные функции:
AZURE_SPEECH_KEY=
AZURE_SPEECH_REGION=
SAFE_BROWSING_API_KEY=
```

Поддерживаются три режима модели:

| Provider | Что заполнить |
| --- | --- |
| `glm` | `GLM_API_KEY`; используется фиксированный стандартный endpoint Z.ai и `glm-5.3-flash`. |
| `qwen` | `QWEN_API_KEY`, `QWEN_BASE_URL`, при необходимости `QWEN_MODEL`; разрешён только Singapore OpenAI-compatible endpoint. |
| `ollama` | `OLLAMA_MODEL`; сервер Ollama должен работать строго на `http://127.0.0.1:11434`. |

Ключ модели **никогда** не вводится в popup расширения.

### 3. Запустить backend

```powershell
npm start
```

По умолчанию он слушает только `http://127.0.0.1:8787`. Проверьте состояние без отправки запроса модели:

```powershell
npm run diagnose
```

Для синтетического стабильного стенда откройте `http://127.0.0.1:8787/demo`.

### 4. Установить расширение

1. Откройте `chrome://extensions` или `edge://extensions`.
2. Включите **режим разработчика**.
3. Нажмите **«Загрузить распакованное»** и выберите папку `extension` из этого репозитория.
4. Откройте popup расширения.
5. Оставьте адрес `http://127.0.0.1:8787` либо укажите свой HTTPS-адрес backend.
6. Вставьте только `LOCAL_ACCESS_TOKEN` из `.env.local` и нажмите «Сохранить». API-ключ модели сюда не вставляется.
7. Обновите уже открытую веб-страницу. Снизу справа появится иконка помощника.

После изменения кода расширения нажмите кнопку обновления в `chrome://extensions`, затем перезагрузите нужную вкладку. Не обновляйте страницу с несохранённой работой в Word/Excel.

### Инструкция для проверяющих на хакатоне

Для проверки готового стенда не нужно устанавливать Node.js или запускать backend локально.

1. Скачайте репозиторий или ZIP-архив проекта и распакуйте его.
2. Откройте `chrome://extensions` в Chrome или `edge://extensions` в Edge.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное** и выберите папку `extension` из проекта.
5. Откройте popup установленного расширения.
6. В поле **Адрес сервера** укажите:

   `https://digital-mentor-api.onrender.com`

7. В поле **Код подключения** вставьте pairing-токен, выданный команде проверяющему через закрытый канал передачи. Это не API-ключ модели и не регистрационный код хакатона.
8. Нажмите **Сохранить**, затем **Проверить подключение**. При первом обращении бесплатный Render-сервис может запускаться несколько секунд.
9. Перезагрузите открытую веб-страницу. Внизу справа появится иконка ИИ Наставника.

Токен подключения является секретом доступа к демонстрационному backend. Его нельзя включать в публичный README, коммит, скриншот или презентацию. После Demo Day токен нужно отозвать и выпустить новый. Если проверяющий не получил токен, его следует запросить у капитана команды или организатора, а не искать в репозитории.

## Как пользоваться

1. Нажмите круглую иконку помощника внизу справа.
2. Используйте **«Изучить страницу»**, чтобы получить обзор видимых элементов.
3. Выберите **«Что это?»** или **«Объяснить раздел»**, наведите курсор на безопасный элемент/раздел и нажмите. `Esc` отменяет выбор.
4. Для своей цели нажмите **«Задать вопрос»**, напишите вопрос и выберите **«Получить ответ»**.
5. После ручного действия на сайте нажмите **«Далее»** — помощник заново посмотрит только разрешённый контекст страницы.
6. Для голоса выберите **«Записать голос»**. В отдельной странице расширения нажмите разрешение микрофона, произнесите вопрос и остановите запись.

Кнопка **«Инструкция пользования»** работает прямо внутри панели, не закрывает её и не требует backend/модели.

## Конфиденциальность и безопасность

- Локально сохраняются выбранный язык, URL backend, временная сессия вопроса в рамках вкладки и pairing token в IndexedDB расширения.
- Вопрос хранится только в `chrome.storage.session` для текущей вкладки, до 30 минут; очищается при завершении задачи или закрытии вкладки.
- Временный серверный cache хранит ограниченный проверенный контекст и ответ в памяти до 10 минут; после перезапуска backend очищается.
- Логи содержат технические метаданные: язык, тип запроса, число элементов, длительность и безопасный код ошибки. В них не должны попадать ключи, токены, тексты вопросов, ответы, URL и документы.
- Для Safe Browsing полный адрес поступает на выбранный backend: при внешнем сервере — по HTTPS, при локальном — остаётся на loopback-компьютере. Затем Google получает только 4-байтовые SHA-256 hash-prefixes; полный URL не отправляется Google и не логируется приложением.
- Фильтрация DOM не может доказать абсолютную анонимность произвольного сайта. Для тестов и демо используйте только синтетические данные.

Подробнее: [карта данных](docs/DATA_FLOW.md), [Safe Browsing](docs/SAFE_BROWSING.md), [голосовой ввод](docs/VOICE_INPUT.md).

## Развёртывание на Render

Проект содержит `render.yaml` для Blueprint на Render Free в Singapore.

1. Запушьте актуальную ветку `main` в GitHub.
2. В Render выберите **New → Blueprint**, подключите репозиторий.
3. Введите в секретах `MODEL_PROVIDER`, `LOCAL_ACCESS_TOKEN`, ключ выбранной модели, а при необходимости Azure и Safe Browsing keys.
4. Дождитесь статуса Live, проверьте `https://<ваш-сервис>/health`.
5. В popup расширения сохраните этот HTTPS-адрес и тот же pairing token.

Бесплатный сервис может «засыпать». Перед Demo Day заранее откройте `/health` и нажмите «Проверить подключение» в popup. Полная инструкция: [RENDER_DEPLOY.md](docs/RENDER_DEPLOY.md).

## Проверки

```powershell
npm test
npm run check
npm run test:browser
```

- `npm test` — 168 unit/integration тестов: API, private context, токены, языки, модельные схемы, voice, TTS, Safe Browsing, Office, cache и race conditions.
- `npm run check` — версии, синтаксис, asset allowlist, manifest, конфигурационные и security-инварианты.
- `npm run test:browser` — Playwright-проверки реального браузерного поведения. Если browser runtime не установлен, это нужно явно зафиксировать, а не считать тест пройденным.

Перед выступлением используйте [каталог ручной приёмки](docs/MANUAL_ACCEPTANCE_CATALOG.md): он содержит 14 реализованных use cases и 30 test cases, а также 4 будущих сценария доступа после хакатона.
