# Как пользоваться «Графом денег»

Сайт помогает выбрать счета для проверки, посмотреть их переводы и сохранить объяснение результата. Он рассчитан на аналитика и на проверяющего, который впервые видит набор данных. Знать графовые алгоритмы не требуется.

Система показывает наблюдаемые факты и предполагаемые роли. Она не устанавливает виновность, законность операций или принадлежность денег. Окончательный вывод требует дополнительного контекста и проверки аналитиком.

## Быстрый старт: одна проверка за несколько шагов

1. Посмотрите название набора и период под заголовком сайта. Надпись «Синтетический пример» означает учебные, искусственно созданные данные.
2. В блоке **«1. Выберите счёт»** нажмите любую строку. Первый счёт выбирается автоматически при загрузке набора.
3. Прочитайте **«Что обратило на себя внимание»** в карточке. Это краткое объяснение наблюдаемой структуры переводов.
4. Нажмите **«Проверить переводы этого счёта»**. Внизу откроется подробный разбор. Выберите цепочку и откройте номер исходной строки операции.
5. Изучите блоки **«Чего не видно в данных»** и **«Что проверить дальше»**. Не делайте вывод только по баллам или цвету узла.
6. Нажмите **«Открыть справку / PDF»** для результата по одному счёту или **«Скачать результаты»** для таблиц по всему набору.

## 1. Как загрузить свои файлы

Нажмите **«Загрузить файлы»** справа вверху и выберите три файла из одного комплекта:

| Файл | Что он содержит |
| --- | --- |
| nodes.parquet | Список всех счетов, стартовые счета и глубина обхода |
| edges.parquet | Сводные связи между парами счетов: сумма и число переводов |
| transactions.parquet | Отдельные операции с датами и суммами |

Нажмите **«Проверить файлы и начать анализ»**. Формат Parquet — формат таблиц, выданный организатором; переименовывать Excel в `.parquet` нельзя. Лимит — 15 МБ на файл и 30 МБ на комплект. Сайт также проверяет размеры таблиц, идентификаторы и совпадение сумм и числа операций между файлами.

При ошибке прочитайте сообщение под полями выбора. Проверьте, что выбраны все три правильных файла из одной выгрузки. Прежний набор остаётся доступен, если новая загрузка не прошла проверку. Повторяющиеся строки переводов не удаляются автоматически: они могут обозначать разные платежи.

После успешной загрузки название набора меняется на «Загруженный набор», обновляются статистика и результаты. **«Вернуться к исходному набору»** возвращает набор, с которым запущен сервер, а не предыдущую загрузку. После перезапуска сервера ранее загруженный набор может потребоваться загрузить снова.

Файлы обрабатываются на сервере приложения. При работе на вашем компьютере это локальный сервер; при размещении сайта на другом сервере файлы передаются ему. В текущей версии внешняя языковая модель не используется.

## 2. Что означают четыре показателя наверху

| Показатель | Как его понимать |
| --- | --- |
| Счета в наборе | Все записи из списка счетов, включая счета без операций |
| Операции перевода | Число отдельных переводов. Пять переводов от A к B — пять операций, но одна направленная связь |
| Сумма всех переводов | Сумма всех операций в выгрузке. Это не размер ущерба и не сумма уникальных денег |
| Счета на краю выгрузки | Счета на четвёртом переходе без видимых исходящих: продолжение могло не попасть в данные |

Кнопка **«?»** возле каждого показателя открывает пояснение. Например, если 10 000 ₸ перевели от A к B и затем от B к C, сумма операций равна 20 000 ₸, хотя это могут быть те же деньги.

## 3. Как найти и выбрать счёт

Слева расположена очередь проверки. Сверху находятся счета с большим приоритетом, рассчитанным по правилам. Номер слева — место в общей очереди; число справа — баллы от 0 до 100.

- Нажмите строку, чтобы открыть её карточку и связи.
- Для поиска вставьте полный идентификатор из выгрузки или несколько его цифр.
- При необходимости выберите предполагаемую роль или группу связанных счетов.
- Если ничего не найдено, нажмите **«Сбросить поиск и фильтры»** и попробуйте снова.

В списке отображаются до 100 подходящих счетов. Под ним указано, сколько показано и сколько найдено. Поиск и фильтры применяются ко всему набору. Экспорт содержит все счета, а не только видимые строки списка.

Идентификатор (`gid`) — обезличенный номер из исходных данных. Это не обязательно реальный банковский номер или IBAN. Кнопка **«Копировать»** в карточке копирует его полностью и без округления.

## 4. Что означают баллы и роли

**Приоритет проверки** показывает, насколько рано счёт стоит рассмотреть по нашим правилам. 90 баллов не означает 90% вероятности нарушения. Рейтинг учитывает положение в сети, связи со стартовыми счетами, оборот и признаки роли.

**Предполагаемая роль** — описание наблюдаемого поведения, которое требует проверки:

| Роль | Объяснение простыми словами |
| --- | --- |
| Сбор средств | На счёт поступают переводы от многих других счетов |
| Распределение | Со счёта отправляют переводы на много других счетов |
| Транзит | Есть поступления и последующие отправления с подходящими суммами в целом и временными признаками |
| Получатель · гипотеза | Видны повторные поступления, но исходящих в наблюдаемой выборке нет |
| Связующее звено | Счёт соединяет разные участки графа и достижим из нескольких стартовых счетов |
| Недостаточно признаков | Правила не дают достаточно оснований для более конкретной роли |

«Недостаточно признаков» не означает, что счёт безопасен или что операции отсутствуют. «Получатель» не означает, что установлено конечное назначение денег. У одного счёта могут одновременно проявляться признаки разных ролей.

В карточке сначала прочитайте краткое объяснение, факты, ограничения и следующее действие. Для подробностей раскройте **«Как получены баллы и роль»**: там находятся слагаемые приоритета, выраженность признаков и альтернативные роли. Полные формулы описаны в README.

## 5. Как управлять картой связей

| Элемент или действие | Что происходит |
| --- | --- |
| Узел | Один счёт; нажмите для выбора и открытия карточки |
| Стрелка | Направление переводов: отправитель → получатель; нажмите, чтобы увидеть сумму и число операций |
| Колёсико мыши / жест прокрутки над картой | Приближение или отдаление |
| Кнопки «+» и «−» | Изменение масштаба без колёсика |
| Перетаскивание пустого места карты | Перемещение видимой области |
| Вписать граф | Подбор масштаба, чтобы все показанные узлы поместились внутри карты; это не полноэкранный режим |
| Прямые связи | Счета, непосредственно связанные с выбранным переводами |
| Связи через посредника | Окружение до двух переходов; стрелки сохраняют своё направление |
| Показать больше счетов | Увеличение числа видимых узлов, максимум до 400 |
| Вернуть все связи счёта | Выход из просмотра отдельной цепочки или выделенных оснований к обычному окружению |

Под картой указано число видимых и доступных в выбранном окружении счетов. Невидимые узлы не удалены из расчёта и выгрузок. Смена масштаба не меняет оценки.

Раскройте **«Как читать карту: цвета, фигуры и стрелки»**. Цвет обозначает роль, а не уровень опасности. Ромб — стартовый счёт анализа. Пунктирная рамка — граница наблюдения. Светлая рамка выделяет выбранный счёт. У других узлов размер зависит от приоритета.

## 6. Как проверить цепочку переводов

Нажмите **«Проверить переводы этого счёта»** и откройте вкладку **«Цепочки переводов»**. Слева выберите маршрут. Справа отображаются счета, суммы по связям и пример последовательности отдельных операций.

Статус относится к выбранному маршруту:

- **«Даты допускают последовательность»**: можно выбрать по одной операции на каждом переходе так, чтобы даты шли вперёд.
- **«Порядок внутри дня неизвестен»**: подходящий порядок возможен только при операциях в одну дату. Точное время не установлено.
- **«Даты не подтверждают этот маршрут»**: для выбранного пути нет даже последовательности с неубывающими датами.

Нажмите **«Показать эту цепочку на графе»** для её отдельного просмотра. **«Все операции связей»** раскрывает операции пар счетов, входящих в путь. Кнопка **«Строка …»** показывает точный источник, дату, сумму, отправителя и получателя.

Суммы на стрелках — обороты каждой пары за весь период. Их нельзя складывать как объём денег, прошедших весь путь. Подходящие даты не доказывают, что через всю цепочку прошли одни и те же деньги.

Показываются до восьми примеров. Поиск берёт один кратчайший путь от каждого достижимого стартового счёта, не более шести переходов; для выбранного стартового счёта также рассматриваются исходящие пути до трёх переходов. Альтернативные пути не перебираются. Отсутствие подходящей последовательности на одном пути не исключает её на другом. Подробности доступны в блоке **«Какие маршруты показаны»**.

## 7. Как изучить даты и основания

**«Переводы по дням»** показывает поступления и отправления выбранного счёта по датам, а также число операций. Это не остаток на счёте: данные о балансе и внешних поступлениях отсутствуют.

**«Основания в операциях»** позволяет выбрать входящие, исходящие или отправления через 1–2 дня после поступлений. Можно попасть сюда нажатием на соответствующий факт в карточке. Нажмите **«Подсветить подтверждающие связи»**, чтобы увидеть их на карте.

Для временных сопоставлений отдельная кнопка показывает возможные предшествующие поступления. Одно исходящее учитывается один раз, даже если подходящих входящих несколько. Сопоставление по дням не устанавливает принадлежность средств.

В таблицах разбора показаны до 100 операций; рядом указано общее количество. Временные сопоставления имеют кнопки для первых 30 исходящих операций. Ограничение отображения не сокращает исходный набор.

## 8. Зачем нужна «Проверка приоритета»

Эта вкладка отвечает на вопрос: останется ли счёт высоко в очереди, если изменить важность признаков?

Показаны текущее место, диапазон мест при восьми вариантах весов и число попаданий в топ-20. Меньший номер места означает более высокий приоритет. Если диапазон широкий, положение счёта чувствительно к настройкам.

Система по очереди меняет каждый вес на ±20% и нормирует сумму весов. Роли и граф остаются прежними. Эти сценарии не изменяют основную очередь и экспорт. Это проверка чувствительности к настройкам, а не доказательство точности.

Ниже можно сравнить наш топ с сортировками только по обороту или числу связей. Дополнительные счета можно открыть нажатием на идентификатор. Различие списков само по себе не означает, что один рейтинг лучше другого.

## 9. Вопросы по счёту

Вкладка **«Вопросы по счёту»** содержит четыре готовые темы: приоритет, роль, даты цепочек и следующее действие. Ответы составляются из расчётов текущего набора. Под ответом доступны примеры исходных операций.

Это локальный помощник без языковой модели и без свободного чата. Он не подменяет экспертное заключение. Показаны до 20 примеров операций с указанием общего числа ссылок.

## 10. Как сохранить результаты

**По всему набору:** нажмите **«Скачать результаты» → «Скачать для Excel (.xlsx)»**. В книге находятся «Приоритеты», «Все счета», «Сообщества» и «О выгрузке». Все счета и группы выгружаются полностью; приоритеты — первые 100 либо весь набор, если он меньше. Ячейки выровнены по центру и имеют границы. Длинные идентификаторы записаны текстом, суммы и оценки — числами. Исключение — суммы с более чем 15 значащими цифрами: они записываются текстом, чтобы Excel не округлил значение. В выгрузке оценки идут от 0 до 1; на сайте они показаны в шкале до 100.

CSV предназначены для программной обработки. Если импортируете CSV вручную в Excel, выбирайте UTF-8, разделитель «запятая», десятичный разделитель «точка» и текстовый тип для gid/top_gids. Обычное открытие CSV может округлить идентификаторы — для него используйте XLSX. Смена оформления ячейки после округления не вернёт утраченные цифры: скачайте новый файл.

**По одному счёту:** в блоке «Подробно о счёте» нажмите **«Открыть справку / PDF»**. Откроется HTML-страница. Для PDF нажмите Ctrl+P и выберите «Сохранить как PDF». Кнопка **«Скачать справку»** сохраняет HTML, который можно открыть без работающего сайта. Справка содержит до трёх цепочек, до 200 операций, ограничения, следующие действия и хеши исходных файлов.

Фильтры списка не изменяют выгрузку по всему набору. Оформление ранее скачанного файла не обновляется автоматически — скачайте его снова.

## 11. Если что-то не получается

| Ситуация | Что сделать |
| --- | --- |
| Счёт не найден | Сбросьте фильтры, проверьте ID и выбранный набор. Не копируйте округлённое число из старого CSV в Excel |
| На карте одна точка | В наборе может не быть связей этого счёта. Посмотрите карточку и сведения о полноте |
| Часть связей скрыта | Нажмите «Показать больше счетов», измените окружение или откройте конкретную цепочку |
| После просмотра цепочки мало узлов | Нажмите «Вернуть все связи счёта» |
| Граф оказался вне видимой области | Нажмите «Вписать граф» |
| Написано «Запуск не найден» | Вернитесь к исходному набору или загрузите свои файлы снова: сервер мог перезапуститься |
| Старые подписи или кнопки после обновления | Обновите страницу Ctrl+F5 |
| В Excel непонятные символы или округлённые ID | Скачайте новый XLSX, а не открывайте старый CSV двойным щелчком |
| Не открывается страница | Убедитесь, что сервер запущен. Команды запуска находятся в README |

## 12. Короткий словарь

| Термин | Значение в этом проекте |
| --- | --- |
| gid / ID | Обезличенный идентификатор счёта из выгрузки |
| seed / стартовый счёт | Точка, с которой начался сбор связей |
| Граф | Карта счетов и переводов между ними |
| Узел / ребро | Счёт / направленная связь между парой счетов |
| Контрагент | Другой счёт, с которым были переводы |
| Группа / сообщество / cluster | Найденная алгоритмом группа связанных счетов; не обязательно реальная организация |
| Приоритет | Место счёта в очереди проверки по правилам проекта |
| Гипотеза роли | Возможное объяснение структуры наблюдаемых переводов |
| SHA-256 / хеш | Контрольная сумма файла, позволяющая сопоставить результат с конкретной исходной выгрузкой |

Для первичного знакомства достаточно первых пяти разделов. Формулы, ограничения метода, исходные схемы и команды запуска находятся в README. Краткое объяснение проекта для жюри — в FOR_JUDGES.md.
