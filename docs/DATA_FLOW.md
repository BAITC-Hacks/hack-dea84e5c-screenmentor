# Карта данных — историческая версия 0.11.0

Текущее правило версии 0.24.17: готовые смыслы разрешены только для Word/Excel. Удалены GitHub fixed routes и любые hostname-specific правила Gmail. На остальных сайтах `concept` всегда null, а назначение определяет модель по очищенной подписи, роли, состоянию и структуре текущей страницы. Актуальный контракт приведён в `HACKATHON_REBUILD_TZ.md`.

В 0.12.0 блоки дополнительно передают роль, примерную позицию, ограниченные структурные счётчики и до шести отфильтрованных дочерних команд. Тексты контейнера, пунктов списка и заголовки документа не читаются. Подробности: [PAGE_BLOCKS.md](PAGE_BLOCKS.md).

Для kk backend дополнительно отправляет провайдеру проверенный русский текст и исходные отфильтрованные подписи для перевода. Основа и перевод хранятся в том же ограниченном кеше. Связанные tooltips проходят прежние фильтры; для GitHub фиксированный путь превращается в понятие и не отправляется. Интернет-поисковикам данные не передаются: функция поиска не подключена.

Расширение имеет host-доступ all_urls для HTTP/HTTPS. Cookies, history, identity, debugger и clipboardRead не запрашиваются.

По нажатию «Изучить страницу» или выбору «Что это?» локально читаются признаки элементов управления. Полный HTML, скрипты, стили, заголовок страницы, значения полей, содержимое редактируемого документа и скриншоты не входят в запрос.

На backend и выбранному провайдеру передаются hostname без пути/параметров, язык, задача, UUID и до шести элементов на блок: id, kind, concept, region, disabled, label, group, role, state. Для «Что это?» — один элемент. Подписи проходят локальные фильтры и повторную проверку формата на сервере. У состояния в запросе к модели человекочитаемое описание.

Фильтры исключают известные личные области DOM, пользовательские ссылки чатов/документов, чувствительные поля, адреса и характерные личные маркеры. На Gmail/Office произвольные подписи разрешены только внутри обозначенных панелей инструментов и меню. Фильтры эвристические: произвольный сайт может поместить имя человека в обычную кнопку. Поэтому нельзя гарантировать отсутствие персональных данных или называть все подписи общедоступными. Пользователь видит это ограничение в панели. Для демонстрации нужны учебные данные.

Временные DOM-ссылки и весь снимок до 36 элементов находятся в памяти вкладки. Не сохраняются на диск. Локально хранятся язык и факт просмотра только известных понятий, а также прежние настройки/прогресс Excel. Неизвестные подписи не попадают в прогресс.

Кеш backend хранит домен, признаки (включая отфильтрованные подписи) и ответы в памяти: до 64 записей, 10 минут. Перезапуск очищает кеш. Production-логи содержат UUID, язык, задачу, число элементов, длительность, кеш и категорию ошибки; без доменов, подписей, ответов и секретов.

API-ключ остаётся в .env.local на backend. С версии 0.11.1 код подключения постоянно хранится в IndexedDB origin расширения; старый session storage используется только для миграции и затем очищается. Popup может сохранить код, проверить наличие и удалить его, но не получает код обратно. Сообщения управления принимаются только от popup этого расширения. Это локальное хранилище профиля, не зашифрованное системное хранилище паролей. Отмена прерывает соединение и блокирует поздний ответ, но уже обработанные токены могут учитываться провайдером. Срок хранения запросов у облачного провайдера задаётся его условиями, а не локальным кешем.

## Целевая модель доступа для production

Текущий pairing-токен остаётся только для локального запуска, хакатона и технического стенда. В production обычный пользователь входит по номеру телефона или email с одноразовым кодом либо продолжает без регистрации с небольшой квотой. Backend выдаёт персональную сессию и применяет лимиты на пользователя; `LOCAL_ACCESS_TOKEN` не показывается конечному пользователю.

Учебные организации получают коды организации или invite-ссылки/QR-коды. Backend проверяет срок действия, лимит активаций и квоту, не передавая организации содержимое вопросов и страниц. Подтверждение статуса через eGov/ЭЦП является отдельным будущим потоком. ИИН не отправляется модели, не используется как пароль и не хранится в расширении; до запуска нужны согласие, политика хранения и юридическая/privacy-проверка.
