Загрузить данные для проверки

Выберите три файла из одного комплекта. Сайт проверит их согласованность и пересчитает результаты.

До 15 МБ на файл и 30 МБ на комплект. Обработка выполняется на сервере приложения. Повторяющиеся строки сохраняются.

3. Сохраните результаты проверки

Для Excel выберите XLSX: идентификаторы и русский текст сохранятся полностью. Фильтры на экране не сокращают выгрузку.

В XLSX — все счета, все группы и первые 100 приоритетов. Справку только по выбранному счёту можно скачать в блоке «Подробно о счёте». CSV предназначены для программной обработки.
